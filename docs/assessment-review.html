Beard's Classroom · Teacher review · v01.0004

A clearer path from baseline to weekly progress

The site already offers a useful collection of individual skill checks. Its next step is a defined skill progression and a consistent measurement routine, so changes in a student's score are easier to interpret.

Review scope: all 43 homepage activity entries, 36 fluency passages, shared scoring/report code, and local navigation. The project contains 82 HTML files before this review document.

What the scores can tell you

These are teacher-created, skill-specific checks. They can show how a student performs on the presented tasks under recorded conditions. The source does not establish grade-placement thresholds, percentile ranks, or equivalent difficulty between randomly generated runs. The Grade 2 and Grade 3 labels describe authored content; they are not demonstrated grade-equivalent scores.

A student reading CVC words, recognizing an answer from four choices, arranging supplied words, and writing a sentence independently is demonstrating four different kinds of performance. Each needs its own goal and score interpretation. Use the site's checks alongside your school's established screening and evaluation tools when determining a broader academic starting point.

How baseline and weekly checks should work

  1. Choose the exact target. Record the skill, level, response format, materials, and allowed support. A percent score on two answers carries different information from the same percent on twenty.
  2. Establish a starting point. Use brief checks across likely prerequisite levels. For the chosen measure, gather a small set of baseline observations under consistent conditions; IRIS describes three to five data points and using the median to summarize baseline performance.
  3. Monitor the same target regularly. Use fresh items with the same difficulty specification: the same vowel-pattern mix, operation/range/regrouping demands, passage level, or response format. Random order alone does not create equivalent forms. Balanced forms would still need evidence before being called equated or validated.
  4. Separate accuracy from speed. Keep the one-minute chime and allow continuation, as requested, but report the first-minute score separately from the whole-session score. An accuracy or reasoning task may need a fixed item count or another agreed duration instead of using the same one-minute interpretation as fluency.
  5. Use the goal's own criterion. Apply the criterion and monitoring schedule selected for that student's goal. Check a pattern over several observations and note instruction/support changes. Keep level changes visible rather than combining different difficulty levels into one unexplained trend.

Remaining specific issues to address

  • Third-grade completion: examples include “The chef ___ the soup” with both stirred/stirs, “Nora ___ her teeth before bed” with brushed/brushes, and possessive items allowing his/its. A single keyed answer is not sufficient if another option is defensible.
  • Sentence Order: “The farmer watered thirsty plants” and “The thirsty farmer watered plants” use the same supplied words and are both grammatical. Exact-string marking needs accepted alternatives or less ambiguous sentence designs. Retries also need separate first-attempt and practice totals.
  • Open Sentence Fill: Stop currently omits the response still being typed; it is saved only by Next. Canceling a teacher grading prompt is treated as an incorrect answer. Save the pending response on Stop and keep ungraded responses pending.
  • Vocabulary: the four answer choices currently require keyboard keys; add tappable choices for phone use. Its 12 prompts across four words are a lesson check rather than broad vocabulary coverage.
  • Older grammar/reading pages: extend the response/Stop/Reset guards to Fact & Opinion, Similes, Tenses, noun/verb, four-part grammar, and Vocabulary. These pages retain delayed advances or response handlers that need the same session protection now applied to math, phonics, Cause & Effect, and Inference.
  • Similes: the present positive/negative bank strongly cues the answer through the presence of “like/as.” Add literal uses of those words as negatives and strengthen weak comparisons so the task measures meaning.
  • Phonics content control: digraph and multisyllable banks mix several additional decoding demands. Some nominal CVC words, such as box, contain more than three phonemes. Tag items by the actual sound/spelling features and use those tags to control the level and weekly mix.
  • Full-bank automatic finishes: a few older pages finish their native session without invoking the shared Stop handler. Unify completion events so the shared clock always freezes with the native report.

Evidence behind the measurement recommendations

  • NCII: Why parallel or equated forms matter — repeated scores should reflect growth rather than an easier or harder form.
  • IRIS: Progress Monitoring — distinguishes mastery of particular skills from general outcome measurement and discusses alternate forms.
  • IRIS: Monitoring Student Progress Toward Meeting IEP Goals — baseline observations, graphing, and monitoring procedures.
  • IRIS: Monitoring & Reporting Student Progress — match the measure, performance criterion, and schedule to the student's goal.
  • NCII: Academic Progress Monitoring Tools Chart — reliability, validity, sensitivity to growth, alternate forms, and decision rules are distinct qualities to evaluate.
